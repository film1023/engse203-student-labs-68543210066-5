1. Component ใดเป็น state owner ของ tasks และ statusFilter เพราะเหตุใด?

   คำตอบ: อยู่ที่ Component 'App' (ตัวแม่หลัก) เพราะชิ้นส่วนย่อยอย่าง TaskEntryForm (ต้องการพิมพ์เพิ่มงานใหม่) และ TaskCard (ต้องการกดสั่งลบงาน) จำเป็นต้องเรียกใช้และอัปเดตข้อมูลของรายการงานทั้งหมดร่วมกันในจุดเดียว


2. ระบุตัวอย่าง Props ลงอย่างน้อย 2 จุด และ callback event ขึ้นอย่างน้อย 1 จุด

   คำตอบ: Props ไหลลงจาก 'App' ไปหา 'TaskCard' และ 'TaskEntryForm' เพื่อส่งตัวแปรข้อมูลและฟังก์ชันจัดการ / ส่วน Event ไหลกลับเมื่อเกิดการกดคลิกปุ่มลบ (onClick) หรือส่งฟอร์ม (onSubmit) ซึ่งจะวิ่งกลับมาเรียกคำสั่ง Callback ฟังก์ชันด้านบนสุดที่ฝั่งตัวแม่ 'App'


3. เมื่อนำ pattern ไปใช้ LAB 4 ต้องเปลี่ยน data contract, validation และ component responsibility อย่างไร?

   คำตอบ: ต้องขยายฟิลด์ข้อมูลเพิ่ม เช่น ลำดับความสำคัญ (Priority), วันที่สิ้นสุด (Due Date) และต้องทำระบบ Validation ตรวจสอบความถูกต้องเพื่อไม่ให้พิมพ์ค่าว่างส่งเข้ามา หรือป้องกันอักขระพิเศษที่เป็นอันตราย
